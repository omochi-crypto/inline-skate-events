# SNSによる大会情報の補完

公式サイトのGitHub Actions収集に加え、ChatGPTの定期タスク「SNSのインライン大会情報」が公開Web検索でSNSを補完調査します。

これはGitHub ActionsがSNSのタイムラインを直接取得する実装ではありません。X・Instagram・Facebookの全投稿の取得は保証しません。ログイン不要の公開情報・検索インデックスで見える投稿が対象です。初回調査ではFacebook上の大会関連発信を検索で確認できましたが、Facebook/Instagramのページ直接取得には失敗しています。定期タスクは設定済みですが、その初回自動実行の完了はまだ確認していません。

## 保存と承認

- 発信元の起点・公式性の根拠・取得制約は events/social-sources.json に記録。
- 投稿URLと主催者の公式募集要項で開催日・会場・種目を照合。
- 確認できる将来大会は標準の [大会候補] Issue として登録。情報不足は [SNS確認待ち] として別管理。
- 閉じたIssueと承認済み大会も含めて重複確認。過去の参加報告は新規掲載しない。
- 新しい候補は取得元リンク付きで利用者へ提示。利用者の「はい／いいえ」で判断し、承認されるまで公開しない。
- 新規候補・中止/日程変更などの重要な変更がなければ通知しない。取得エラーは候補ゼロと混同せず知らせる。

投稿の年月日と開催日を分けます。画像や年省略などで開催日が不明なら推測せず保留します。SNS転載や個人投稿だけを公式発表として扱いません。アカウントにログインしたり、非公開グループ・DMへアクセスしたり、SNSへ投稿する処理はありません。
