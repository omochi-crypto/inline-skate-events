# Repository scope

Work only in omochi-crypto/inline-skate-events. Never modify the separate weather repository.

Fix collection, Actions, reporting and website problems autonomously within reasonable bounds. Run meaningful regression tests and inspect Actions logs after changes. Preserve Issue and commit history. Never delete historical Issues or force-push.

Human review is mandatory before an event is published. Agents must never post an /approve command for a real event, add real events to approved.json as a test, or weaken the approval gate. Use /preview for live Issue validation and temporary fixture data for approval-positive tests.

Prefer official federation/organizer evidence. Separate uncertain dates and historical events. Do not invent future editions or event dates. Keep source errors and ambiguous records visible in the report.
